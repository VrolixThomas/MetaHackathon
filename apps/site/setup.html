Getting started

Set up your review workspace.

The signed macOS download and recorded demo are still being prepared. Development requires repository access and integration wiring. This guide does not imply a published or fully integrated release.

What you need

  • A supported macOS machine and microphone permission for the desktop app.
  • A Meta Model API key with access to Muse Voice Transcribe and Muse Spark.
  • An ElevenLabs API key with text-to-speech permission, plus an accessible voice ID.
  • GitHub access to the pull requests you want to review.

When the app is released

  1. Download the DMG from the latest release, open it, and copy the app to Applications.
  2. Open the app and use Settings to configure provider keys and GitHub access. Keep credentials out of review comments and transcripts.
  3. Allow microphone access when macOS asks. Open a review and hold Space to speak; release to send your question. Press Space again to interrupt the reply.

Developer checkout

The repository uses Node 22.12 or newer and Bun 1.3.9 or newer. Follow the root README for the current integration branch and voice service setup.

bun install --frozen-lockfile
bun run type-check
bun run build
bun run dev

The voice sidecar is a separately frozen Python service. Its setup, dependency lock and local verification commands live in services/voice/README.md. Main-process wiring is documented in apps/desktop/src/main/voice/README.md. Development does not require activating the Node fallback.

How voice behaves

The microphone opens during push-to-talk. The transcript becomes a turn in the agent review loop. A short acknowledgement can play while scenario work continues, followed by the answer. Interruption stops playback and cancels the active response; an old response must not resume.

Recorded author intent, inferred explanations and actual execution results remain distinct. A drafted review comment is not posted until you explicitly confirm it.

If setup is incomplete

A missing key, voice ID, provider entitlement or microphone permission prevents live voice. Verify those settings first. A local unsigned build is not a signed release; do not disable macOS protections to treat it as one.
